# big-file-workbench
大文件上传测试工作台

## 使用

直接用浏览器打开 `index.html`，或在仓库目录启动任意静态文件服务器后访问页面。填写支持分片接收的 HTTP(S) 上传接口，选择文件并设置分片大小、并发数和文件字段名，然后开始上传。接口需允许当前页面来源进行 CORS 请求。

页面按配置大小将文件切片，并以并发 `POST multipart/form-data` 请求发送。每个请求包含以下字段：

| 字段 | 说明 |
| --- | --- |
| `file`（可配置字段名） | 当前二进制分片，文件名沿用原文件名 |
| `chunkIndex` | 分片序号，从 `0` 开始 |
| `totalChunks` | 分片总数 |
| `uploadId` | 本次上传的唯一标识 |
| `fileName` | 原始文件名 |
| `fileSize` | 原始文件大小，单位字节 |
| `chunkSize` | 当前分片大小，单位字节 |

接口可通过 `uploadId` 和 `chunkIndex` 识别、保存并重组分片。页面展示每个分片的 HTTP 状态码和最多 300 个字符的响应内容；任何分片失败时会停止派发后续分片并取消其他进行中的请求。该工具只负责客户端测试，不提供服务端存储或合并逻辑。
