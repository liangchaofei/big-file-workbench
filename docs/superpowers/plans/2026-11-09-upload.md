# File Upload Implementation Plan

> Execute inline in this session using superpowers:executing-plans.

**Goal:** 可比较整文件和分片上传的大文件实验室。
**Architecture:** React + Vite，Node 原生 HTTP，流式落盘和 SHA-256，Worker 增量哈希。
**Tech Stack:** Node >=22.12, React, Vite, hash-wasm, Playwright。
**Spec:** docs/superpowers/specs/2026-11-09-upload-design.md

## Global Constraints
本地绑定 127.0.0.1；默认 8 MiB 分片、3 并发；文件大小安全整数；分片最大 64 MiB；数据目录 gitignore。

## Review Focus
缺片及错误哈希必须拒绝合并；损坏或中断分片不能算完成；非法大小与路径拒绝；暂停后不继续启动分片；刷新后同一内容恢复。
