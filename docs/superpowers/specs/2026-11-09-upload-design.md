# 大文件上传实验室
用户已确认 React + Vite、Node.js 的本地上传测试台方案。
采用原生 HTTP 流式上传，避免后端将整个文件读入内存。对比整文件上传与固定大小分片上传。前端在 Worker 内增量计算 SHA-256，后端合并时计算 SHA-256 校验。可配置分片大小与并发数，显示进度、速度、耗时，暂停及继续。刷新后重新选择同一文件可恢复分片。
方案比较：整文件上传用于基线；分片上传用于大文件、重试和恢复；不引入对象存储以避免外部账号依赖。
限制：本地单进程演示，不作为多用户公网存储服务。用实测成功大小表达下界，不声称浏览器通用上限。测试文件生成器在磁盘创建稀疏文件，避免浏览器一次构造巨型 Blob。
